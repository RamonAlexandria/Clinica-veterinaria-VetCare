🐾 VetCare — Clínica Veterinária | HTML5 Semântico & CSS3

Um site institucional completo e responsivo para uma clínica veterinária, desenvolvido a partir de um processo completo de UI/UX Design no Figma e traduzido para código com foco total em HTML5 semântico (zero <div>s), acessibilidade e design responsivo.
🚀 Diferenciais do Projeto

    Zero <div>s: Todo o layout e estruturação de telas foram construídos utilizando exclusivamente elementos semânticos do HTML5 (<header>, <main>, <section>, <article>, <nav>, <form>, <fieldset>, <address>, <footer>, etc.).

    Fidelidade ao Figma: Reprodução exata da identidade visual criada na etapa de UI Design, respeitando tipografia, paleta de cores, espaçamentos e raios de borda.

    Acessibilidade: Estruturação lógica com formulários bem mapeados (<label>, <input>, <select>), marcações semânticas e navegabilidade amigável.

    Design Responsivo: Adaptado para diferentes resoluções (desktops, tablets e smartphones) através de Flexbox e Media Queries.

🛠️ Tecnologias Utilizadas

    Figma: Elaboração do fluxo de usuário, wireframes, design system e protótipo interativo.

    HTML5: Estruturação 100% semântica e acessível.

    CSS3: Layouts fluidos com Flexbox, variáveis de estilo, efeitos de transição/hover e media queries para responsividade.

🎨 Etapas do Desenvolvimento (UX/UI para HTML/CSS)
Etapa 1 — Fluxo do Usuário

    Fluxo Principal: Home ➔ Serviços ➔ Detalhes do Serviço ➔ Veterinários ➔ Perfil do Veterinário ➔ Contato/Agendamento

Etapa 2 — Wireframe

    Mapeamento funcional e estrutural de baixa fidelidade para definir a disposição dos elementos e hierarquia de conteúdo de todas as páginas.

Etapa 3 — UI Design (Guia de Estilos & Componentes)

    Diretrizes Visuais Flexíveis:
    
    Paleta de Cores: Uso do tom verde corporativo como cor primária para ações de destaque/botões, alinhado ao azul escuro institucional no cabeçalho e rodapé. Aplicação de planos de fundo ilustrados, neutros e fundos claros para leitura legível.
    Tipografia: Baseada na família Inter / Sans-Serif, variando pesos (Bold, Medium, Regular) e tamanhos proporcionais para garantir hierarquia clara entre títulos, rótulos e corpo de texto.
    Componentes Reutilizáveis: Estruturas de cabeçalho e rodapé padronizadas, cards adaptáveis para exibição de serviços/veterinários, formulários com campos interativos e botões estilizados com estados de hover.

Etapa 4 — Protótipo Navegável

    Construção das conexões interativas no Figma simulando a jornada completa do cliente até o formulário final de agendamento.

Etapa 5 — HTML/CSS (Código Final)

    Desenvolvimento das páginas utilizando HTML semântico e CSS modularizado, garantindo que o padrão visual e de alinhamento se mantivesse em todo o projeto.

📂 Páginas do Projeto

    Início (index.html): Apresentação da clínica, banner principal, diferenciais e visão geral da VetCare.

    Serviços (servicos.html): Catálogo dos serviços oferecidos (Consultas, Vacinação, Exames, Cirurgias, etc.).

    Detalhes do Serviço (detalhesServico.html): Detalhamento sobre procedimentos específicos, recomendações e cuidados.

    Veterinários (veterinarios.html): Apresentação da equipe médica veterinária da clínica.

    Perfil do Veterinário (perfilVeterinario.html): Informações detalhadas, especialidades e currículo do profissional.

    Contato/Agendamento (contatoAgendamento.html): Interface com formulário completo para marcação de consultas e listagem dos canais diretos de atendimento.
